HOW TO UPDATE YOUR EXISTING GITHUB SITE
1. Unzip this package.
2. Open your existing GitHub repository.
3. Click Add file > Upload files.
4. Drag ALL files and the assets folder from this package into the repository upload page.
5. GitHub will show the existing files as updates/replacements. Commit the changes.
6. If older unused image files remain in the assets folder, they are harmless; the website no longer references them.
7. Wait about 1–2 minutes and refresh your GitHub Pages link.

IMPORTANT
Keep index.html, style.css and script.js at the root of the repository. Do not put them inside another folder.

GITHUB PAGES — QUICK DEPLOY
---------------------------
1. Create a new GitHub repository.
2. Upload ALL files and the entire assets folder exactly as provided.
3. Open the repository Settings.
4. Go to Pages.
5. Under “Build and deployment”, choose “Deploy from a branch”.
6. Select the main branch and /(root), then Save.
7. GitHub will provide the public website link after deployment.

IMPORTANT
---------
- Keep the assets folder name unchanged.
- Do not rename files unless you also update their references in index.html/style.css.
- The website does not require Firebase, a database, or any external libraries.
- HP and Telegram details on the Contact tab are clickable.
- The page uses only relative paths, so it works on GitHub Pages repositories.
